# LTTube for Fire TV

Ad-free YouTube on Fire TV. Runs on its own: no PC needed.

## Install
In the **Downloader** app, enter:

    github.com/lknicks9-a11y/lttube-firetv/releases/latest/download/LTTube-TV.apk

The same link always gives the newest version.

## What's in it
- Home rows: Continue watching, Subscriptions, Recommended, Music, Gaming, Live, Podcasts, Movies & trailers, Your channels, History
- Search with suggestions; channels (Videos, Shorts, Live, Playlists) with Subscribe; playlists
- Player: up to 4K, original audio (no auto-dub), subtitles, speed, sponsor skipping (SponsorBlock), autoplay, resume where you left off
- Subscriptions and history are kept on the TV. Import your YouTube subscriptions once from LTTube on your PC (Settings row → Import subscriptions).

## Remote
- In the player: ◀ ▶ skip 10 s, Select pauses, ≡ opens quality / audio / subtitles / channel / up next.
- Back leaves the player.

## Build
Every push to `main` builds `LTTube-TV.apk` with GitHub Actions and publishes it as the latest release.
