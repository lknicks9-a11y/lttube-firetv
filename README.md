# LTTube for Fire TV

A Fire TV app for LTTube. It connects to LTTube running on your PC (same Wi-Fi);
the PC does the ad-free YouTube work, the TV just shows it and handles the remote.

## Remote
- Arrows: move around. Select: open / play-pause.
- On a video: left/right skip 10 s, up shows the player controls.
- Play/pause, fast-forward and rewind buttons work everywhere.
- ≡ (menu): video options for the highlighted video. **Hold ≡** to pick a different PC.
- Back: goes back; on the home page it leaves the app.

## Install on Fire TV
In the **Downloader** app, enter:

    github.com/lknicks9-a11y/lttube-firetv/releases/latest/download/LTTube-TV.apk

This link always points to the newest build.

## Build
Every push to `main` builds `LTTube-TV.apk` with GitHub Actions and attaches it to a release.
